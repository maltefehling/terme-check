Alle Daten bleiben in diesem Browser auf diesem Gerät. Nichts wird hochgeladen. Namen gibst du hier nirgends ein – die Zuordnung Nummer → Name steht nur auf deiner ausgedruckten Liste.

2 · Ergebnisse einsammeln

Schüler zeigen nach dem Abgeben einen QR-Code (enthält auch ihre Übungsstatistik). Wer auf einem anderen Gerät geübt hat, zeigt zusätzlich den „Übungsnachweis“ von der Startseite. Beides kannst du jederzeit scannen, auch schon vor dem Test.

Du kannst auf zwei Arten scannen – such dir aus, was in der Stunde besser passt:

📷 HerumgehenDu gehst mit dem iPad (Rückkamera) durch die Klasse und scannst die Codes an den Plätzen. Nach jedem Scan siehst du kurz Nummer, Punkte und Note.
🖥 ScanstationDas iPad (Frontkamera) oder ein Laptop mit Webcam steht vorne. Wer fertig ist, hält seinen Code kurz vor die Kamera. Angezeigt wird nur „Nr. … erfasst“, keine Punkte – dazu, welche Nummern noch fehlen.

3 · Ergebnisse

Gespeichert wird jeder Scan sofort hier im Browser dieses Geräts (nicht im Internet). Safari kann Daten von Webseiten löschen, die man länger nicht geöffnet hat – sichere die Notenliste deshalb noch am Testtag als PDF.

Klick auf eine Zeile zeigt die Aufgaben und Antworten. ½ = Wert richtig, Form nicht (z. B. nicht ganz vereinfacht). „Hand“ = per Code eingetragen, dann ohne Einzelantworten. „verl.“ = so oft hat das Gerät den Test verlassen (App gewechselt, Home-Taste; die automatische Bildschirmsperre wird während des Tests verhindert). Übung (gezählt wird nur echtes Üben: eine Aufgabe ab 5 s Bearbeitung, ein Tag ab 3 Aufgaben, eine Runde nur, wenn mind. 80 % ihrer Aufgaben echt bearbeitet wurden): Runden = komplette Probetests, Themen = Fünfer-Übungen, % = beim 1. Versuch richtig. Die Übungszahlen stammen vom Schülergerät; wer auf mehreren Geräten übt, wird zusammengezählt, sobald alle Geräte gescannt sind.
