# Terme-Check

Übung und Online-Test zu **Terme und Gleichungen** (Klasse 8, Realschule) – Ausmultiplizieren, Ausklammern, Summen multiplizieren, binomische Formeln, Faktorisieren, Gleichungen mit Klammern, Bruchgleichungen.

- Üben: https://maltefehling.github.io/terme-check/
- Test: https://maltefehling.github.io/terme-check/#test

Alle Aufgaben werden per Zufall erzeugt (keine Schulbuchaufgaben). Kein Server, keine Namen: Ergebnisse gehen per QR-Code direkt an die Lehrkraft. Aufbau wie der [Wurzel-Check](https://github.com/maltefehling/wurzel-check).
